DUSTLINE — a round-based tactical FPS in the Foundry Yard, built with
three.js 0.187.0 (vendored, byte-identical) and no network access: two
teams of five, a buy phase, bomb plant/defuse objectives, grenades,
bot teammates and opponents with routes and reactions, headshots,
recoil and spread, a minimap, and round/match flow with a full HUD.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
